# NaijaBuy&Sell V38

V38 adds a complete real-estate listing/search layer:
- List property
- Houses, apartments, land, shops, offices, warehouses, estates and short-let
- Sale, rent and lease
- Property details
- Property photos
- Search filters for property type, purpose, state, city and price
- Approved listings only in public property search

Payment/escrow remains separate and is not activated.
