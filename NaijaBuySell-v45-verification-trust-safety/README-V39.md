# NaijaBuy&Sell V39

V39 adds:
- Dedicated property details page
- Property photo gallery
- Seller/agent profile link
- Verification status display
- Property verification status fields
- Verification audit foundation
- Admin verification guidance
- Property search cards linking to details
- Public property pages restricted to approved listings

Verification is a workflow foundation. It does not itself prove ownership, title, agency authority or government approval. Those claims require evidence and appropriate review.
