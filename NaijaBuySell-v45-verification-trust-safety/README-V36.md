# NaijaBuy&Sell V36

V36 adds listing management and moderation on top of V35.

Features:
- Seller My Listings
- Edit listing details
- Delete/soft-delete listing
- Editing sends listing back to pending moderation
- Admin moderation queue
- Approve/reject listings
- Role/ownership checks through Supabase integration

This remains a development-stage marketplace. Payment/escrow is not activated.
