# NaijaBuy&Sell V37

V37 expands the marketplace to Real Estate & Properties.

Included:
- Real Estate & Properties category
- Real estate SEO landing page
- Property types: houses, apartments/flats, land, shops, offices/commercial, warehouses, estates/developments and short-let
- Sale/rent/lease purposes
- Property database fields
- Seller profile and verification fields
- Seller profile page
- Backend migration and implementation notes

Payment/escrow is not activated in this version.
